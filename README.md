# # Introduction to mBot2

## What is mBot2?

**mBot2** is a smart educational robot designed for learning coding, robotics, and engineering in *ICT lessons*. It is powered by **CyberPi**, which acts as the main brain of the robot and controls its sensors, screen, and motors.

## What Can mBot2 Do?

- Move accurately in different directions using encoder motors.
- Detect obstacles, colors, and lines with its built-in sensors.
- Display text, charts, and animations on its full-color screen.

## Three Important Features of mBot2

1. **CyberPi Microcontroller:** Supports both block-based coding and Python programming.
2. **Smart Sensors:** Includes an ultrasonic sensor and a quad RGB sensor for line following.
3. **Expandable Design:** Allows students to add extra electronic modules and mechanical parts.

## Why We Use mBot2 in ICT

We use mBot2 in ICT lessons because it makes abstract programming concepts real and interactive, helping us understand how software controls hardware.
